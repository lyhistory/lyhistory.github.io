我是做IT的，我从来不信科技会让生活更美好，
我永远是最后一个用智能设备的，我做过系统，所以从来不相信任何系统，
人做的没有不出错的系统，功能越复杂，出错概率越大，
尤其是所谓新能源，我应该是永远不会碰的，除非某一天我买不到油车了

世界是个巨大的草台班子，我见过名校毕业的人在搞系统的时候能多么敷衍，
一个系统运行了一两年出了问题才发现当时依赖的第三方组件理解错了

沉溺于空调的我们大概很难想象没有空调的年代一样的舒服，当然我是指环境不恶劣的地方，

现在的科技产品只会卖某个功能，根本不会考虑是否有可能对人体产生危害，
比如难以清洗的豆浆机，简易的还好，复杂的豆浆机有可能在出水槽发霉，
比如我用过某个大牌的豆浆机，被虫子的尸体堵死了，他们没考虑这是南方，
某个企业家推荐的电饭锅也是被虫子搞短路了，
更可怕的是某个大牌加湿器，我无意间发现其内芯上长满了黑色霉菌，不仔细都看不清，
