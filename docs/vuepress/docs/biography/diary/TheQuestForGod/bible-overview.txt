圣经导读：写给不了解宗教的东方读者


一、圣经讲了一个什么故事

圣经的总体故事可以概括为：上帝创造了世界和人；人违背上帝，罪和死亡进入世界；上帝从亚伯拉罕及其后裔开始一个修复计划；耶稣的死与复活开启新约；最终，圣经描述死人复活、世界被更新，神与人同住。

圣经由多卷书组成，写作时间跨越一千多年，包含历史记载、法律、诗歌、智慧格言、先知讲话、人物传记、书信和用象征性梦境、画面写成的作品。这些书共同呈现一条主线。下面按故事发生的顺序讲。


1. 好世界怎样裂开

故事从创造开始。上帝造天地、光、海、植物、动物，最后造人。圣经把人描述为照着上帝的形像被造，被托付管理世界，也被邀请与上帝同行。创造完成时，上帝看着一切所造的，说：“甚好。”

接着登场的是亚当和夏娃。在圣经故事以及受它影响的西方传统里，他们被视为人类的始祖：第一对男女，也是后文所有人类的共同祖先。上帝把他们安置在伊甸园，允许他们吃园中各种果子，只禁止他们吃“分别善恶树”的果子，并警告他们吃的日子必定死。

蛇就在这时出现。创世记第3章只称它为“蛇”，没有给它一个魔鬼的名字，也没有交代它的来历。蛇先问夏娃：“神岂是真说不许你们吃园中所有树上的果子吗？”夏娃回答，园中的果子都可以吃，只有园中央那棵树的果子不能吃，也不能摸，免得死。蛇接着说：“你们不一定死；神知道你们吃了以后眼睛就明亮了，你们便能像神一样知道善恶。”

夏娃见果子好看、又能使人有智慧，就摘下来吃了，也给亚当吃。两人发现自己赤身露体，就用无花果树叶遮身，听见上帝的声音便躲起来。被问起时，亚当把责任推给夏娃，夏娃推给蛇。上帝随后作出审判：人被赶出伊甸园，耕作、生育和夫妻关系都带上痛苦，死亡也进入人类历史。

上帝审判蛇时，还说了一句后来很重要的话：“女人的后裔要伤你的头，你要伤他的脚跟。”这是圣经第一次出现“蛇最终会被击败”的应许；后面的旧约故事和先知书多次回到这个主题。

被逐出伊甸后，亚当和夏娃生了该隐和亚伯。该隐种地，亚伯牧羊。两人献祭时，上帝看中亚伯的祭物，没有看中该隐的；该隐发怒，上帝警告他罪正伏在门前，他却在田野杀了弟弟亚伯。这是圣经记载中的第一起谋杀，也表明罪已经从第一对夫妻蔓延到下一代。亚当和夏娃后来又生了塞特，人类继续繁衍。

创世记第5章把从亚当到挪亚的家谱列了出来。到了挪亚的时代，圣经记载人类的恶行越来越大，地上充满强暴；上帝决定用洪水审判世界，并吩咐挪亚造一只方舟。挪亚一家和带进方舟的动物在洪水中存活；洪水退去后，上帝以彩虹作为不再用洪水毁灭大地的记号。

洪水之后，挪亚的后代重新繁衍。他们想建一座城和一座通天的塔，为自己立名；上帝变乱他们的语言，使他们彼此听不懂，人类从此分散到各地。创世记11章末尾又从挪亚的儿子闪Shem往下排出家谱，一直引到亚伯拉罕。到第12章，故事从全人类转向亚伯拉罕和他的家族。


2. 亚伯拉罕家族与应许

亚伯拉罕大约生活在公元前2000年前后。以撒、雅各、约瑟是随后几代，约瑟的故事通常定在公元前19至前18世纪。上帝呼召亚伯拉罕离开本地本族，向他作出三项承诺（圣经里叫“应许”）：后裔众多、得到土地、万国要因他得福。亚伯拉罕和妻子撒拉年老才生下以撒；亚伯拉罕和撒拉的侍女夏甲还生了以实玛利。

以撒长大后娶了利百加，生下双胞胎以扫和雅各。以扫是哥哥，雅各是弟弟。以扫先为了一碗食物，把长子的名分（家族继承权）让给雅各；后来雅各又冒充以扫，骗取了父亲本来要给长子的祝福。兄弟因此结怨，雅各逃离家乡，多年后才与以扫和好。雅各后来改名以色列，所以“以色列人”指他的后代。亚伯拉罕、以撒、雅各这三代人，被称作以色列人的族长；雅各的十二个儿子则成为以色列十二支派的祖先。圣经没有把这几位族长写成完人，而是记录了他们的撒谎、偏心和家庭冲突。

在十二个儿子中，雅各特别偏爱约瑟，哥哥们嫉妒他，把他卖到埃及。约瑟在埃及因替国王法老解梦而得到重用，负责管理粮食；后来饥荒来临，他的家族到埃及求粮，约瑟与兄弟相认，并把全家接到埃及居住。从亚伯拉罕到约瑟是四代人；从约瑟到耶稣还隔着一千多年。这个故事解释了以色列人后来为什么会在埃及生活，下一段出埃及就是从这里接上。


3. 从奴隶到一个民族

几百年后，以色列人在埃及做了奴隶。上帝呼召摩西，借十灾击打埃及，带领他们出埃及。逾越节的羔羊、过红海、西奈山立约、十诫，都围绕一件事：上帝把一群奴隶救出来，使他们成为属于自己的百姓。

出埃及后，以色列人在旷野多次抱怨、怀疑和背叛。摩西上山领受律法时，山下的百姓造了金牛犊；那一代人最终倒在旷野，由约书亚带领新一代进入应许之地，也就是迦南——大致相当于今天的以色列、巴勒斯坦一带。摩西的姐姐米利暗、哥哥亚伦，也出现在这段故事中。


4. 王、圣殿、分裂与流亡

进入这片地区后，以色列还没有国王，由被称为“士师”的领袖处理争端、组织抵抗。这一时期出现底波拉、基甸、参孙等士师，也有路得、撒母耳等重要人物。士师记反复出现一个循环：百姓背离神，受压迫，呼求，神兴起拯救者，短暂平安，然后再次背离。

百姓后来要求像周围国家一样，有一个国王统治他们。撒母耳先选定扫罗作国王，后来又选定大卫。扫罗成为第一任国王，但统治失败；大卫接替扫罗成为国王，大约在公元前1000年把耶路撒冷定为首都。上帝应许大卫家族永远有人坐在王位上，这成为后来期待一位永远君王的根源。大卫的儿子所罗门建造圣殿——以色列人敬拜上帝的中心建筑——以智慧闻名，但晚年偏离神。他死后，王国分裂为北方的以色列王国和南方的犹大王国。

北方的以色列王国在约公元前722年被亚述帝国毁灭；南方的犹大王国在约公元前586年被巴比伦毁灭，耶路撒冷和圣殿被烧，许多百姓被掳到巴比伦，这段时期称为“流亡”。国家与圣殿被毁之后，一批被称为“先知”的人继续发声。圣经中的先知，是替上帝向百姓说话、批评社会不公并呼唤他们悔改的人。

圣经中提到的先知包括以利亚、以利沙、以赛亚、耶利米、以西结、但以理、何西阿、阿摩司、弥迦、约拿等人。他们一面批评偶像崇拜、社会不公和表面宗教，一面预告审判之后还有恢复：上帝会更新人的内心，与人另立新约，赐下圣灵（圣经中理解为上帝的能力与同在），并兴起一位受膏的君王（弥赛亚）。后来波斯王居鲁士在约公元前538年允许被掳的百姓回到家乡。所罗巴伯重建圣殿，以斯拉重建律法生活，尼希米重建城墙；以斯帖和末底改则在波斯宫廷里救了犹太人。这次回归没有让一切恢复原状，百姓仍在等待更大的复兴。

旧约并不只有这条从亚伯拉罕到流亡的故事线。它同时收录了约伯记、诗篇、箴言、传道书和雅歌；这些书不是继续讲国家大事，而是保存古以色列人的祷告、诗歌和人生经验。约伯记讲一个受尽苦难的义人质问上帝，最后没有得到“你一定是犯了罪”的简单解释，而是被带去看自己无法理解的广阔世界。诗篇收录大量祷告和诗歌，有赞美，也有抱怨、悔罪、愤怒和信靠。箴言收集处世智慧，传道书讨论人生的虚空和限度，雅歌写爱情。


5. 耶稣：旧约的线索在这里汇合

旧约故事结束到耶稣出生之间，还隔着波斯、希腊和罗马的统治时期；犹太人一直在等待一位应许的君王。

新约说，耶稣大约在公元前4年出生，母亲是马利亚。马利亚的丈夫约瑟是耶稣名义上的父亲，不是生父；这里的约瑟与前面雅各的儿子约瑟同名，但两人相隔近两千年。

当时有一个叫约翰的先知在旷野传道，劝人改变方向、准备迎接上帝要来的拯救者。他给人施洗，作为悔改的记号，所以被称为“施洗约翰”。耶稣也接受了约翰的洗礼，随后在旷野受到魔鬼的试探，并开始宣讲：“上帝的国近了，你们要悔改，信福音。”这里的“上帝的国”指上帝的统治，“福音”就是好消息。

他先后叫彼得、安得烈、雅各、约翰等渔夫，以及为罗马政府收税的税吏马太来跟随他；这些人成为他的门徒，也就是跟随和学习的人。他治病、驱逐邪灵、平静风浪、使死人复活，用比喻讲上帝的统治；他与犹太教领袖发生冲突，因为他对律法的解释、对罪人和非犹太人的接纳，挑战了当时的宗教秩序。多马、抹大拉的马利亚、犹大，也在这场旅程中出现。

最后，耶稣在耶路撒冷和门徒吃最后的晚餐，被门徒犹大出卖，被犹太教领袖控告，被罗马总督彼拉多判处钉死在十字架上。记载耶稣生平的福音书说，他死后第三天复活，向门徒显现，然后升天。

新约作者用旧约中的几条线索解释耶稣：亚当代表人类的失败，耶稣代表人类重新顺服上帝；摩西带领以色列人脱离埃及的奴役，耶稣被视为带领人脱离罪和死亡；大卫是以色列最著名的国王，耶稣被视为上帝应许的那位永远君王；圣殿是以色列人敬拜和献祭的中心，耶稣被视为人与上帝相遇的新途径；旧约用宰杀祭牲的方式处理罪，新约把耶稣的死解释为一次完成、不再重复的献祭；先知耶利米预告上帝要与人另立新约，新约认为这约在耶稣里开始；他的复活则被视为世界更新的开端。对新约作者来说，旧约不是被废弃的旧故事，而是得到延续和实现的应许。


6. 故事没有在十字架结束

耶稣升天后，门徒继续传讲他复活的消息。在一个叫五旬节的犹太节期，他们经历圣灵降临（圣经用这个词指上帝的能力与同在），开始向耶路撒冷、犹太各地、撒玛利亚，直到世界各地传讲耶稣。彼得成为早期领袖；司提反成为第一位因信仰被杀的殉道者；腓利向非犹太人传道；扫罗原本参与迫害教会，后来转而相信耶稣，后来以保罗这个名字为人所知，成为向非犹太人传教最重要的使徒（被差派传教的领袖）。使徒行传记录了保罗的几次旅行、教会内部的冲突，以及耶路撒冷会议怎样决定非犹太人不必先成为犹太人才能信耶稣。

新约的许多卷是书信。保罗写给罗马、哥林多、加拉太、以弗所、腓立比、歌罗西、帖撒罗尼迦等地的教会，也写给提摩太、提多、腓利门等个人；其他书信处理迫害、信心与行为、爱、真理、错误教导和盼望。这些信不是抽象的理论文章，而是早期教会遇到具体问题时写下的回信。巴拿巴、路加、马可也是保罗传教和写作中的重要同伴。

最后是启示录。它使用大量象征性的梦境和画面，写作背景是罗马帝国统治下受压的教会。书中有给七间教会的信、天上的宝座、被杀的羔羊（象征耶稣）、代表邪恶势力的龙和兽，以及象征压迫帝国的巴比伦；最后是审判、新天新地和新耶路撒冷城。主流解释通常不把它当作推算具体日期的日历，而把它视为对邪恶失败、羔羊得胜、上帝与人同住的象征性宣告；也不把书中的龙、兽、数字和灾难逐项套到今天的新闻事件或人物上。

主线可以简写为：创造 → 人类背叛 → 应许 → 亚伯拉罕 → 以色列 → 出埃及 → 大卫王 → 先知与流亡 → 回归与等待 → 耶稣 → 教会 → 新天新地。

时间上可以这样记：亚伯拉罕约生活在公元前2000年前后；约瑟约在公元前19至前18世纪；出埃及约公元前13世纪；大卫成为国王约公元前1000年；北国亡于前722年；南国亡于前586年；回归始于前538年；耶稣出生约前4年；钉十字架和复活约公元30年；保罗传教约在40至60年代；耶路撒冷圣殿在70年被罗马毁灭；启示录传统上认为写于90年代左右。

若只记五个关键人物：亚当（人类为什么需要拯救）、亚伯拉罕（修复计划从一个家族开始）、摩西（上帝把奴隶带出来并立约）、大卫（应许一位永远的君王）、耶稣（新约把他视为那位君王和救主，也是整本圣经故事的中心）。


二、常见误解与概念澄清

1. 正典：圣经由多卷书组成

这里的“正典”，指被主流教会认定为圣经的书目。

华语世界最常见的《和合本》是新教的六十六卷：旧约三十九卷，新约二十七卷。天主教和东正教的旧约还会多出几卷，东正教承认的范围又略多一些。这种差异来自不同古代传统对正典范围的理解，不是文本被谁改动。所有主流传统共同承认的核心故事，是同一条线。

犹太教只承认希伯来圣经，不承认新约，也不把它叫“旧约”，而叫“塔纳赫”或“希伯来圣经”。“旧约/新约”是基督教的分法。《多马福音》《犹大福音》等作品不在主流正典内，本文不采用它们补充圣经故事。


2. 旧约与新约指向同一位神

圣经讲的是同一位神。旧约强调他的公义、圣洁和应许，新约强调这些应许在耶稣里怎样成全。不是“旧约的神严厉，新约的神温柔”，而是同一位神在更长的故事里逐步展开他的计划。


3. “约”是立约关系，不是商业合同

“旧约”和“新约”里的“约”，不是签完就各自履约的商业合同，更像一种立约关系：上帝作出承诺，也提出要求；人则以信靠和顺服回应。整本圣经可以看成“上帝怎样与人重建关系”的记录。


4. 几个关键词的圣经含义

神/上帝：不是冷漠的命运，也不是众多神明中的一个；他是创造者、立约者、审判者，也是怜悯者。耶和华是上帝向摩西启示的立约之名，不同译本也译作“上主”或“雅威”。

罪：不只是“做坏事被抓到”，更是指人与神的关系破裂、人把自己放在中心、偏离神的心意。圣经也把罪描述成一种会奴役人的力量。

律法：不只是法律条文，也包括教导和生活方式。对以色列来说，律法是上帝与这个民族立约后的生活规范。

弥赛亚/基督：不是耶稣的姓，而是“受膏者/君王”的称号。古代以色列会把油倒在被选定为王的人头上，表示他被上帝选中；新约说耶稣就是那位应许的君王。

福音、信、悔改：福音就是“好消息”；信指信靠、交托和忠诚，不只是承认某个事实；悔改指转身、改变方向，不只是自我惩罚。

教会、圣殿：教会不是建筑物，而是相信耶稣的人组成的群体；圣殿是上帝与人同在的象征，新约把耶稣的身体看作真正的圣殿。

先知、门徒、使徒：圣经中的先知代替上帝向人说话、指出当下问题并呼唤人改变方向；门徒是跟随、学习的人；使徒是被差派出去传教并讲述耶稣复活的人。

永生、审判：圣经对终局的描述是身体复活、世界更新、神与人同住，而不是灵魂永远脱离身体存在。审判包括对邪恶的清除和对公义的恢复。永恒不只是时间无限延长，也指与神同在、不再受死亡和败坏辖制的新状态。


5. 蛇、魔鬼、撒旦的经文线索

常见说法是“魔鬼就是蛇”。更准确的表述是：新约把创世记里的蛇和魔鬼、撒旦联系起来；旧约本身并没有在创世记里给蛇一个“魔鬼”的名字，也没有交代它的来历。

创世记第3章只称它为“蛇”，说它比田野一切的活物更狡猾。它质疑上帝的话、否认后果、承诺人可以通过违背神变得“像神一样”。上帝对蛇的审判是用肚子行走、吃土，这是古代故事中的羞辱性象征，不是动物学解释。

旧约里的“撒旦”更像“控告者/敌对者”的称呼，不一定一开始就是专有名字。约伯记开头，撒旦出现在天上的场景中，作为控告者质疑约伯；撒迦利亚书第3章也有控告的画面；历代志上21章1节说撒旦激动大卫数点百姓。旧约对魔鬼的来历没有系统交代，更多是把它写成抵挡神、控告人、引诱人犯罪的力量。

新约把线接了起来：《启示录》12章9节说“大龙就是那古蛇，名叫魔鬼，又叫撒旦”，20章2节再次说“那古蛇，就是魔鬼，又叫撒旦”。耶稣在旷野受魔鬼试探；约翰福音8章44节称魔鬼为“说谎的、杀人的”；十字架和复活被描述为对魔鬼的审判与胜过，最终结局是被扔进火湖（象征最终的审判和毁灭）。

但主流圣经文本没有给蛇一段详细的“堕落天使前传”，也没有把它写成有名字、与上帝对等的存在。后来一些文学和传说补充了这些内容，它们不属于主流正典。可以简单记成：蛇（创世记）→ 控告者/撒旦（旧约个别经文）→ 古蛇＝魔鬼＝撒旦（启示录）→ 被耶稣击败、最终受审判。圣经把魔鬼描述为受造世界中的抵挡者，而不是与上帝对等的另一位神；其结局是失败。


6. 启示录的象征与写作背景

启示录充满象征，通常不被当作推算具体日期的日历。它的写作目的是安慰正在受压的教会，书中宣告邪恶最终失败、羔羊（象征耶稣）已经得胜、上帝要与人同住。主流解释通常不把龙、兽、数字和灾难逐项套到今天的新闻事件或人物上。


7. 不同书卷使用不同体裁

创世记开头是古代故事，诗篇是诗歌，箴言是智慧格言，先知书是针对当时处境的讲话，福音书记载耶稣的生平和门徒的见证，书信是具体教会问题的回信，启示录是用象征性梦境和画面写成的文学。阅读时需要区分体裁，不能把诗歌、异象或比喻都按同一类文体解释。
