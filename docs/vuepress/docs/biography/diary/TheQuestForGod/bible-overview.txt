圣经导读：给不了解宗教的东方读者


一、先用一句话说清楚

圣经讲的是这样一个故事：上帝创造了一个好的世界，人选择背离他，世界因此破碎；上帝拣选一个家族、一个民族，借摩西、大卫和先知预备拯救；最后耶稣来到，死而复活，开启新的约；跟随他的人把消息传开；故事的终点，是一个被更新、没有死亡和眼泪的新世界。

你可以把圣经想成一部“由很多作者、跨越一千多年写成的文库”，而不是一本从头到尾按时间排列的单一历史书。它里面有历史叙事、法律、诗歌、智慧格言、先知讲话、人物传记、书信和异象。


二、圣经到底是什么

1. 它不是一本书，而是一套书

华语世界最常见的《和合本》圣经，是新教的六十六卷：旧约三十九卷，新约二十七卷。天主教和东正教的旧约还会多出几卷，例如多俾亚传、友弟德传、智慧篇、德训篇、玛加伯书等；东正教承认的又略多一些。这些差异不是“谁改了圣经”，而是不同古代传统对“正典范围”的理解不同。所有主流传统共同承认的核心故事，是同一条线。

圣经的故事发生在古代中东（今天的以色列/巴勒斯坦、埃及、伊拉克一带），不是欧洲；它后来深刻影响了西方文明，但它的起点在亚洲西部。

犹太教只承认希伯来圣经，不承认新约；他们也不把这本书叫“旧约”，而叫“塔纳赫”或“希伯来圣经”。“旧约/新约”是基督教的分法。

后来的《多马福音》《犹大福音》等作品，不被主流教会纳入正典；本文不采用它们来补圣经故事，也不采用现代小众教派对圣经的改写。主线只按主流新旧约讲。

2. “约”不是合同，而是关系

“旧约”和“新约”里的“约”，不是商业合同，更像一种立约关系：上帝选择一个对象，作出承诺，也提出要求；人则以信靠和顺服回应。整本圣经可以看成“上帝怎样与人重建关系”的记录。

3. 它关心的不是现代科学问题

圣经不是现代科学教材，也不是一本按今天标准写的编年史。它回答的核心问题是：世界从哪里来？人为什么受苦？罪和死亡从哪里来？人和神的关系出了什么问题？还有没有修复的可能？所以，读圣经要先看它是什么体裁、在讲什么，而不是拿它去和物理教科书逐句对照。


三、先弄懂几个容易误解的词

神/上帝：圣经里的神不是冷漠的命运，也不是众多神明中的一个；他被描述为创造者、立约者、审判者，也是怜悯者。

耶和华：这是圣经里上帝向摩西启示的立约之名（四字神名）的中文音译；不同译本也译作“上主”或“雅威”。它强调上帝是自有永有、守约的那一位。

罪：不只是“做坏事被抓到”，更是指人与神的关系破裂、人把自己放在中心、偏离神的心意。圣经也把罪描述成一种会奴役人的力量。

律法（妥拉）：不只是法律条文，也包括教导和指引；在旧约里，它是上帝与以色列立约的生活方式。

圣洁：不是“碰不得的神秘力量”，而是“被分别出来、属于神、与污秽有别”。

弥赛亚/基督：不是耶稣的姓，而是“受膏者/君王”的称号。新约说耶稣就是那位应许的君王。

福音：意思是“好消息”，不是一本新书，也不是一套新法律。

信：不是“明知没有证据还硬信”，而更接近“信靠、交托、忠诚”。圣经里的信心，既包含承认自己不知道，也包含把生命交给所信的对象。

悔改：不是自我惩罚，而是转身，改变方向。

教会：不是建筑物，而是“被呼召出来的群体/会众”。

圣殿：上帝与人同在的象征，不是普通建筑；新约把耶稣的身体看作真正的圣殿。

永生、审判：圣经的终点不是“人变成幽灵飘在云上”，而是身体复活、世界更新、神与人同住。审判也不只是“算账”，还包括恢复公义、清除邪恶。

先知：不是算命先生，而是替神说话、指出当下问题、呼唤人回转的人。

门徒/使徒：门徒是跟随、学习的人；使徒是被差派出去作见证的人。福音书里耶稣有一批核心门徒，其中一些人后来成为教会的使徒。


附：信、理性、永恒、时间

信和理性不是敌人。圣经没有要求人把脑子关掉；它邀请人根据见证、历史、良心和受造界去考察。但“信”最后不是“我全算明白了”，而是“我把自己交托给这位神”。理性可以扫清障碍，却不能代替信任。

圣经说神是永恒的，不受受造时间的限制。但“永恒”不只是“时间无限延长”，更是神与人同在的新状态。启示录的终点是身体复活、新天新地，不是灵魂永远飘在云上。时间是不是上帝创造的？主流神学多数会说“是，时间是受造世界的一部分”，但“永恒里还有没有时间”这类问题，神学家有不同说法，不应当讲成已经定论。

如果用圣经回答终极三问，可以这样概括：

我是谁？——我是上帝创造的、身体与灵魂一体的受造者，按神的形象被造，也因罪受损。

我从哪里来？——从上帝的创造而来，不是前世投胎，也不是毫无意义的偶然。

我将到哪里去？——身体复活，接受审判，进入新天新地，或与神隔绝。“天堂/地狱”是这个过程的一部分，不是全部。


四、旧约故事线

旧约不是按“历史书—诗歌—先知书”这么简单一路读下来的；它更像一组从不同角度讲同一个民族和同一个信仰传统的书。下面按故事发生的顺序梳理。

1. 创造与破裂（创世记1—11章）

故事从创造开始。上帝创造天地、光、海、植物、动物，最后造人。人不是普通动物，而是“照着神的形象”被造，被托付管理世界。创造完成后，上帝看着一切所造的，说“甚好”。

接着出现蛇。蛇引诱夏娃怀疑上帝的话，告诉她吃了分别善恶树的果子就能“像神一样”。亚当和夏娃吃了果子，开始羞耻、躲避上帝，并把责任推给别人。人被赶出伊甸园，死亡和苦难进入人类历史。

之后是该隐杀亚伯、洪水与挪亚、巴别塔。人类越来越多，罪也越来越深；但上帝没有把故事停在毁灭上，他仍然保留拯救的线索。

2. 一个家族与一个应许（创世记12—50章）

上帝呼召亚伯拉罕离开本地，应许他：后裔众多、得土地、万国要因他得福。亚伯拉罕和妻子撒拉年老才有儿子以撒；亚伯拉罕与夏甲还有以实玛利。以撒有雅各和以扫两个儿子；雅各后来改名以色列，他的十二个儿子成为以色列十二支派的祖先。约瑟被哥哥们卖到埃及，后来在饥荒中救了全家。

这一段的核心不是“好人一生平安”，而是：上帝拣选了一个并不完美、甚至常常犯错的家族，仍然守住自己的应许。

3. 出埃及与西奈之约（出埃及记—申命记）

以色列人在埃及做奴隶。上帝呼召摩西，借十灾击打埃及，带领以色列人出埃及。逾越节的羔羊、过红海、西奈山立约、十诫，都是以“上帝拯救一群奴隶，使他们成为属于自己的百姓”为背景。

但以色列人在旷野不断抱怨、背叛；摩西上山西奈，他们却造金牛犊。最后一代人倒在旷野，约书亚带领新一代进入应许之地。

4. 士师、王国与分裂（约书亚记—列王纪）

进入迦南后，以色列经历“士师”时代：底波拉、基甸、参孙、路得、撒母耳等人物出现。士师记反复出现一个循环：百姓背离神—受压迫—呼求—神兴起拯救者—短暂平安—再次背离。

后来百姓要求立王。扫罗是以色列第一位王，但失败；大卫接续，成为最重要的君王，耶路撒冷成为首都，上帝应许大卫家永远有王位。所罗门建圣殿，但晚年偏离神。所罗门死后，王国分裂为北国以色列和南国犹大。

北国先被亚述帝国毁灭（约公元前722年）；南国后来被巴比伦毁灭，耶路撒冷和圣殿被烧（约公元前586年）。这就是“流亡”。

5. 先知、流亡与归回（列王纪、先知书、以斯拉记、尼希米记、以斯帖记）

在王国危机中，先知不断出现：以利亚、以利沙、以赛亚、耶利米、以西结、但以理、何西阿、阿摩司、弥迦、约拿等。他们不是只会预言未来，而是指责偶像崇拜、不公义、虚伪宗教，呼唤百姓回到与神的约中；同时预告审判之后的恢复、新的心、新的约、圣灵、弥赛亚。

巴比伦之后是波斯。波斯王居鲁士允许犹太人归回，所罗巴伯重建圣殿，以斯拉重建律法生活，尼希米重建城墙。以斯帖记讲的是波斯宫廷中犹太人被拯救的故事。归回并不等于一切都好了；百姓仍在等待更大的复兴。

6. 诗歌与智慧（约伯记、诗篇、箴言、传道书、雅歌）

这些书不按时间线讲故事，而是记录人对神的赞美、哀哭、疑问、感恩、智慧反思和爱情。约伯记尤其重要：一个义人为什么受苦？上帝没有给约伯一套“因果公式”，而是让他看见自己的有限。诗篇则包含赞美、哀诉、悔罪、咒诅和信靠，是整本圣经最真实的“祷告样本”。


五、新约故事线

1. 耶稣（四福音书）

新约的中心人物是耶稣。福音书说，他由马利亚所生，约瑟是他的法律上的父亲，不是生父；家谱追溯到大卫。施洗约翰在旷野预备道路，耶稣受洗、受试探，开始宣讲“神的国近了，你们要悔改，信福音”。

耶稣呼召渔夫彼得、安得烈、雅各、约翰，也呼召税吏马太等门徒。他医病、赶鬼、平静风浪、使死人复活，用比喻讲论神的国；他与宗教领袖冲突，因为他对律法的解释、对罪人和外邦人的接纳，挑战了当时的宗教秩序。

最后，耶稣在耶路撒冷与门徒吃最后的晚餐，被犹大出卖，被宗教领袖控告，被罗马总督彼拉多判处钉十字架。福音书说，他死后第三天复活，向门徒显现，然后升天。基督徒认为，他的死承担了罪，他的复活战胜了死亡，开启了新的创造。

2. 教会（使徒行传）

耶稣升天后，圣灵在五旬节降临，门徒开始向耶路撒冷、犹太全地、撒玛利亚，直到地极传福音。彼得成为早期领袖；司提反成为第一位殉道者；腓利向外邦人传道；扫罗（后来的保罗）原本迫害教会，后来归信，成为向外邦人宣教最重要的使徒。

使徒行传记录保罗的几次旅行、教会内部的冲突、耶路撒冷会议如何决定外邦信徒不必先成为犹太人才能信耶稣，最后保罗被押送到罗马。

3. 书信（罗马书—犹大书）

新约的很多卷是书信。保罗写给罗马、哥林多、加拉太、以弗所、腓立比、歌罗西、帖撒罗尼迦等教会，也写给提摩太、提多、腓利门等个人。主题包括：因信称义、恩典与律法、教会合一、复活、圣灵、爱、受苦、假教师、伦理生活。

其他书信（希伯来书、雅各书、彼得前后书、约翰一二三书、犹大书）处理逼迫、信心与行为、爱、真理、假教导和盼望。它们不是抽象神学论文，而是早期教会面对具体问题时的牧养信件。

4. 启示录

启示录用大量象征性异象，安慰在罗马帝国压力下的教会：七封信、宝座、羔羊、龙/古蛇、兽、巴比伦、审判、新天新地、新耶路撒冷。它不是一本可以拿来算具体日期的“末日密码”，而是用象征语言说：邪恶看似强大，但最终失败；羔羊已经得胜；神要与人同住，擦去一切眼泪。


六、旧约和新约怎么接上

把整本圣经串起来，可以记成一条线：

创造 → 人类背叛 → 应许 → 亚伯拉罕 → 以色列 → 出埃及 → 大卫王 → 先知与流亡 → 归回与等待 → 耶稣 → 教会 → 新天新地

旧约不断出现几个主题，新约说这些主题在耶稣身上得到成全：

1. 应许的后裔：创世记3章15节说，女人的后裔要伤蛇的头。基督徒把这条线理解为：上帝从一开始就预告，蛇最终会被击败；新约把耶稣看作那位胜过蛇的人。

2. 亚伯拉罕的祝福：上帝应许万国要因亚伯拉罕得福；新约说，耶稣使这个应许临到外邦人。

3. 出埃及：上帝把奴隶带出埃及；新约把耶稣的死与复活看作一次更大的“出埃及”，把人从罪和死亡中带出来。

4. 大卫的君王：上帝应许大卫家永远有王；新约称耶稣为“大卫的子孙”“弥赛亚/基督”。

5. 圣殿与献祭：旧约用圣殿和祭牲处理罪；新约说，耶稣自己的身体就是圣殿，他的死是一次性的赎罪祭。

6. 新的约：先知耶利米预告，上帝要与百姓立新的约，把律法写在心上，赐下新心和新灵；新约说，这约在耶稣里开始实现。

7. 新的创造：先知以赛亚、启示录都讲到新天新地、不再有死亡和眼泪；新约的终点不是“离开世界”，而是世界被更新。

所以，旧约不是“废弃的前传”，新约也不是“另一本宗教书”。新约的作者们认为：旧约的应许、献祭、君王、先知、圣殿、出埃及、流亡和归回，都在耶稣身上找到了继续和成全。基督徒把耶稣之前叫作“旧约/旧约时代”，把耶稣之后叫作“新约/新约时代”。


七、蛇、魔鬼、撒旦：圣经自己怎么讲

你问“魔鬼也就是蛇，对吧”。更准确的说法是：新约把创世记里的蛇和魔鬼/撒旦联系起来；旧约本身并没有在创世记里给蛇一个“魔鬼”的名字，也没有交代它的“前世”。

1. 创世记里的蛇

创世记3章只称它为“蛇”，说它比田野一切的活物更狡猾。它做的事是：质疑上帝的话、否认后果、承诺人可以通过违背神变得“像神一样”。它不是说“我是魔鬼”，也没有一段“堕落天使”的独白。上帝对蛇的审判是用肚子行走、吃土——这是古代叙事中的羞辱性象征，不是动物学解释。

2. 旧约里的“撒旦”

“撒旦”这个词本来更像“控告者/敌对者”的称呼，不一定一开始就是一个专有名字。约伯记开头，撒旦出现在天庭，作为控告者质疑约伯；撒迦利亚书3章也有控告的画面；历代志上21章1节说撒旦激动大卫数点百姓。旧约对“魔鬼”的来历没有系统交代，更多是把它写成抵挡神、控告人、引诱人犯罪的力量。

3. 新约把线接起来

新约明确把蛇、魔鬼、撒旦放在一起：《启示录》12章9节说“大龙就是那古蛇，名叫魔鬼，又叫撒旦，是迷惑普天下的”；20章2节再次说“那古蛇，就是魔鬼，又叫撒旦”。耶稣在旷野受魔鬼试探；约翰福音8章44节称魔鬼为“说谎的、杀人的”；罗马书16章20节说神要践踏撒旦在脚下。

新约也说，耶稣的十字架和复活是对魔鬼的审判与胜过（歌罗西书2章15节；希伯来书2章14节），最终的结局是魔鬼被扔进火湖（启示录20章10节）。

4. 不要用后期传说补“前传”

主流圣经没有给蛇一段详细的“堕落天使前传”，也没有把它写成一个有名字的、与上帝对等的存在。后来一些文学和传说给蛇补了“前世”，但那些不是创世记的叙述，也不应当当作圣经主线。你可以把圣经的线索简单记成：

蛇（创世记）→ 控告者/撒旦（旧约个别经文）→ 古蛇=魔鬼=撒旦（启示录）→ 被耶稣击败、最终被审判。

魔鬼不是与上帝平起平坐的“另一位神”。圣经的立场不是二元论：上帝是创造主，魔鬼是受造世界里的抵挡者，最终不能胜过上帝。

所以，一句话：按新约的线索，蛇就是魔鬼/撒旦；按旧约的叙述，蛇首先是那条被咒诅的蛇，圣经没有给它一段“天使前传”。


八、主要人物速查

起初：亚当、夏娃（人类的代表）；蛇（引诱者）；该隐、亚伯（第一对兄弟，谋杀与流血）；挪亚（洪水与方舟）。

族长：亚伯拉罕（信心之父，领受应许）；撒拉（应许之子以撒的母亲）；以撒（应许的延续）；以实玛利（亚伯拉罕的另一个儿子，阿拉伯民族的祖先传统）；雅各/以色列（十二支派的祖先）；以扫（雅各的哥哥，以东人的祖先）；约瑟（被卖到埃及，后来拯救全家）。

出埃及：摩西（领以色列出埃及、传律法）；亚伦（大祭司）；米利暗（女先知）；法老（压迫者）；约书亚（带领进入应许之地）；喇合（耶利哥的妓女，因信救探子）。

士师与王国初期：底波拉（女士师）；基甸（以少胜多）；参孙（大力士，悲剧英雄）；路得（摩押女子，大卫的曾祖母）；撒母耳（最后的士师，膏立扫罗和大卫）；扫罗（第一任王，失败）；大卫（最重要的王，诗篇传统）；所罗门（建圣殿，以智慧闻名）。

分裂与先知：罗波安（南国犹大）；耶罗波安（北国以色列）；以利亚（对抗巴力先知）；以利沙（以利亚的继承者）；以赛亚（预言审判与安慰）；耶利米（预言新约，见证耶路撒冷毁灭）；以西结（流亡中的异象）；但以理（巴比伦/波斯宫廷中的犹太人）；何西阿、阿摩司、弥迦、约拿（小先知，呼唤悔改与公义）。

归回：所罗巴伯（重建圣殿）；以斯拉（重建律法生活）；尼希米（重建城墙）；以斯帖、末底改（波斯宫廷中拯救犹太人）。

新约：马利亚（耶稣的母亲）；约瑟（耶稣法律上的父亲）；施洗约翰（预备道路）；耶稣（中心人物，弥赛亚/基督）；彼得、安得烈、雅各、约翰（渔夫门徒，早期领袖）；马太（税吏，传统认为是福音书作者）；多马（怀疑后认信）；犹大（出卖耶稣）；抹大拉的马利亚（复活见证人）；彼拉多（罗马总督，判耶稣钉十字架）；司提反（第一位殉道者）；保罗（外邦人的使徒，书信作者）；巴拿巴、提摩太、路加、马可（宣教与写作同伴）。


九、一条大致时间线

下面的年代是传统/大致估算，学者之间会有不同：

亚伯拉罕：约公元前2000—1800年
出埃及：约公元前13世纪（争议很大）
大卫作王：约公元前1000年
北国以色列被亚述毁灭：约公元前722年
南国犹大/耶路撒冷被巴比伦毁灭：约公元前586年
波斯王居鲁士允许归回：约公元前538年
耶稣出生：约公元前4年
耶稣钉十字架/复活：约公元30年
保罗宣教旅行：约公元40—60年代
耶路撒冷圣殿被罗马毁灭：公元70年
启示录成书：传统认为约公元90年代


十、读圣经最容易误会的地方

1. 不要把它当成一本按时间顺序排好的历史书。旧约前面的历史书之后，会插入诗歌、智慧书和先知书；新约的书信也不是按写作时间排列。

2. 不要忽略体裁。创世记开头是古代叙事，诗篇是诗歌，箴言是智慧格言，启示录是异象文学。不同体裁要用不同方式读。

3. 不要把“旧约的神”和“新约的神”当成两个神。圣经自己讲的是同一位神：旧约强调他的公义、圣洁和应许，新约强调这些应许在耶稣里的成全。

4. 不要用后期传说填补圣经没写的细节。圣经对蛇的“前世”、对魔鬼的完整来历、对天使的层级，都没有给出系统说明；很多流行说法来自后来的文学、传说或推测，不是主流圣经主线。

5. 不同宗派对一些细节有不同解释，例如创世记1章怎么读、预定与自由意志怎么协调、启示录的符号怎么解。这些争议真实存在，但不影响主线：创造、堕落、拣选、拯救、耶稣、教会、新天新地。


十一、最后用一句话记住整本圣经

上帝造了一个好的世界，人把它弄坏了；上帝拣选一个家族、一个民族，借摩西、大卫和先知预备修复；最后耶稣死而复活，把新的约、新的心和新的创造带进来；故事结束于一个新天新地，神与人同住，死亡和眼泪被擦去。

如果你只记五个人，可以记：

亚当：人类为什么需要拯救。
亚伯拉罕：上帝从一个人、一个家族开始他的修复计划。
摩西：上帝把奴隶带出来，赐下律法，显出他愿意与人立约。
大卫：上帝应许一位永远的君王，让以色列和后世有盼望。
耶稣：基督徒相信，他就是那位君王、那位救主，也是整本圣经的答案。
