## 键盘
Ctrl 键下面你看到的“铁丝”一般是金属平衡丝/稳定杆（stabilizer wire），它和塑料“剪刀脚”一起用：剪刀脚负责上下行程，铁丝负责宽键不翘边。普通小 Ctrl 有时只有剪刀脚、没铁丝；如果是宽左 Ctrl / 宽右 Ctrl，就会带铁丝。
